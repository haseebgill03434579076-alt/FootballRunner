# Football Runner

A simple portrait Android football runner game inspired by the supplied reference image.

## Gameplay
- Tap left/right or drag to move the player.
- Collect footballs for coins and score.
- Collect trophies for a bigger score bonus.
- Avoid mystery-box obstacles.
- Tap the pause button at the top.
- After game over, tap anywhere to restart.

## Build
Open this folder in Android Studio with a recent Android Gradle Plugin.
Then use:
Build > Build Bundle(s) / APK(s) > Build APK(s)

The app uses only Android SDK APIs and has no external runtime dependencies.
